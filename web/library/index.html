    01 / LANGUAGE MODEL
    文字与对话
    在你自己的电脑上完成
    网页只帮你把主题、材料和要求打成一份任务书。下载下来，用你平时顺手的工具做完，再把正文导回来，接着编辑、记笔记或者试听。
    1. 在创作台写好这次的主题与材料
    2. 下载任务书，在你自己的电脑上做完
    3. 把做好的正文导回创作台
    在 GitHub 上看源码 ↗去准备任务书 ↗
    网页只负责准备任务书和接收正文，不会替你启动任何程序，也不经手你的 Key。
    填好就能在这里直接生成；不填也没关系，看、听、找期次、笔记、导出都不受影响。
    02 / VOICE
    声音，由你决定
    打开 MiMo 开发平台 ↗语音接入文档 ↗
    目前的规则是语音合成与音色设计限时免费，具体以服务方的实时说明为准。
    生成时，这段文字和你选定的参考音会发给你自己配置的语音服务。如果浏览器连不上，就下载源码放到自己的环境里用。
    回到声音工作室 ↗
    每次生成都走你自己的账号，费用以服务商为准。站点不附带任何人的私有音色。
    03 / TAKE IT WITH YOU
    放进网易云，随身听
    先下载生成的音频，再用自己的网易云账号扫码登录、传入音乐云盘。
    在自己电脑上上传的方式
    源码用户可以运行下面的命令。扫码由本人完成；本页不会读取你原有账号的 Cookie，也不会自动上传。
    ncm-cli login
ncm-cli cloudupload upload "你的音频.wav"
    浏览器里直接扫码与上传需要配套账号服务，这一版先保留下载和本人登录入口。
    04 / BACK IT UP
    带走，或者留个备份
    这个站开放在 GitHub Pages 上，背后没有别的服务在跑。你的内容只存在这台设备的浏览器里，换设备、换浏览器或者清缓存之前，先备份一份。
    备份是一个文件，里面装着你的内容、笔记、角色，以及你导入的材料正文。

    第一步稿子真的写完了吗看文件有没有真的更新，拦「说写了、其实没写」
    
        
    第二步够不够长数正文汉字，短要解释，水要回炉
