# 「让 AI 讲人话 / 讲清代码」GitHub 调研

> 调研日期：2026-09-12
> 触发：真实痛点——干代码项目时 AI 回复看不懂，看不懂就不知道底层逻辑怎么改

> stars 数字均来自实际 API 返回

## 0 最重要：本机藏着对症机制 `MessageDisplay` hook

- 本机 Claude Code 2.1.261 二进制确认存在 `MessageDisplay` hook；官方 changelog 第 2386 行有记录
- 二进制内注释：`Display-only: the stored message and what the model sees are untouched.`
- 输出契约：`Display-only: replaces the delta on screen without changing the stored message.`
- 意义：能在回答显示到屏幕那刻就地重写，不改变 AI 实际做的事
- 现成参考：`esc5221/cc-gemini-rewrite`（7★，MIT），README 原句「Claude Code's technical answers are often hard to read — the conclusion buried, no clear next step」，挂 `MessageDisplay` hook + `/rewrite` 命令
- 注意：它默认接 OpenAI 兼容端点，撞零云依赖红线；机制可抄本体不宜装

## 0.1 关键坑：`outputStyle` 字段本机已废弃

- 实测 `claude --output-style` 报 unknown option
- 官方 explanatory 插件 README 自认 outputStyle 已 deprecated，改用 SessionStart hook
- 所以 attention-span / awesome-claude-output-styles 教的 `"outputStyle": "..."` 配置本机跑不通，只能取其规则文本

## 3 结论：用哪些

判断标准不是 stars，是三条硬约束：① 本机 2.1.261 能真跑 ② 零云依赖 ③ 治「看不懂代码→不知道改哪」

**推荐组合（不整体安装第三方，只抄零件）：**

1. 主解：自建 `MessageDisplay` hook，本地脚本把难懂回答改写成大白话
   - 机制抄 cc-gemini-rewrite；规则抄 DreambigOu/ELI5 + attention-span + agent-style
2. 辅解：SessionStart hook 注入「必读最小集」
   - 思路抄 persistent-handoff（极简）+ recall（本地摘要）+ post_compact_reminder（压缩后重注入）
3. 收尾：`check_reply.py` 机器检查
   - 思路抄 agent-style 的 style-review 层

**不建议直接装**：cc-gemini-rewrite（要云端点）、attention-span/awesome-claude-output-styles（配置字段已废）、agent-style CLI（pip 新依赖，抄规则即可）。
