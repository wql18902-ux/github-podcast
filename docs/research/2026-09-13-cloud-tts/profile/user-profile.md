# 用户画像

- 使用场景：github-podcast 每日一期，中文口播稿，常驻声音克隆音色。
- 目标长度：正文 8500-10500 汉字，约 51-62 分钟。
- 现有本地路线：VoxCPM2 2B GGUF Q8 + Metal，16G 内存的 Mac，整期自动跑。
- 成本关注点：电费、机器占用时间、免费额度、声线一致性、离线可用性。
- 运维约束：`DOUBAO_TTS_KEY` 只从环境变量读；不能写进文件或日志。
- 内容约束：删除只进废纸篓；`episodes.log` 只追加；核心数据必须有来源。
- 决策偏好：先看真实价格和限制，不接受“感觉差不多”；需要一个小步可验证的下一步。
