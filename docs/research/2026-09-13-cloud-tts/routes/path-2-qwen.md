# 路径 2：千问 TTS

- 难度：中
- 前置条件：千问或百炼 API Key
- 试听成本：免费额度内 0 元
- 一期付费成本：Qwen3-TTS-Flash 约 1.36 元

## 推荐试点

1. `qwen3-tts-flash`：0.8 元/万计费字符，中文按 2 字符/汉字。
2. `qwen3-tts-instruct-flash`：同价，可用自然语言控语速和情绪。
3. `qwen-audio-3.0-tts-plus`：1.4 元/万计费字符，音质更高。
4. `cosyvoice-v3.5-flash`：0.8 元/万计费字符，适合比较不同声音体系。

## 免费额度

- 常见 TTS 模型各 1 万计费字符，90 天。
- 一个汉字算 2 个字符，所以一份额度约等于 5000 汉字。
- 多个模型额度独立，可用于不同模型的 A/B，不适合当长期生产额度。

## 可行性

- 资金：✓
- 技能：✓
- 时间：✓
- 工具：需要新增调用脚本

## 判断

云 TTS 里最适合先试。价格最低、免费额度足够听 2-3 个短样，后续迁移成本也最低。
