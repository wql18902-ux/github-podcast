# 路径 1：继续本地 VoxCPM2

- 难度：低
- 前置条件：现有 MacBook Air M4 / 16GB 和本地模型
- 一期现金成本：约 1-2 分
- 一期机器时间：约一期音频时长

## 节点链

| 节点 | 操作 | 风险 | 处理 |
|---|---|---|---|
| 1 | 保持 `scripts/tts_local.py` 主路线 | 音色和降噪仍需持续盯 | 用现有 `--denoise deesser` |
| 2 | 用免费云额度做 A/B 试听 | 需要额外接入脚本 | 只做试听，不动生产入口 |
| 3 | 只有云路线明显更好时才接 fallback | 引入 API Key 和计费风险 | Key 只从环境变量读 |

## 可行性

- 资金：✓
- 技能：✓
- 时间：✓
- 工具：✓

## 判断

当前最合理的默认选择。除非云音质明显胜出，或者机器时间成为瓶颈，否则没有理由为每期省几十分钟而迁移主链路。
