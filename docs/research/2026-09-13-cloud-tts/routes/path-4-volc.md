# 路径 4：火山方舟 / 豆包语音

- 难度：中
- 一期正常价：公开价约 4.25 元
- Agent Plan 等效：约 2.30 元
- 活动首购价：约 1.43 元
- 免费试用：豆包语音独立入口常见 2 万字符/半年

## 关键口径

- 方舟公开模型价格表：豆包 TTS 5 元/万字符，声音复刻 8 元/万字符。
- 豆包语音独立计费：语音合成模型 2.0 后付费可到 3 元/万字符，资源包更低。
- Agent Plan：`doubao-seed-tts-2.0` 每万字符消耗 1350 AFP。
- 方舟语音体验页和产品页的免费字符数曾分别出现 20000 和 5000，需以控制台为准。

## 可行性

- 资金：✓
- 技能：✓
- 时间：✓
- 工具：需要按方舟或豆包语音接口接入

## 判断

如果音质优先，豆包值得试。它正常价明显高于千问，但在 Agent Plan 或限时活动里能把成本压到 1.4-2.3 元/期。若只是做每日播客，暂不值得为纯 TTS 单独订阅 Agent Plan。
