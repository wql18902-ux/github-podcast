# 云 TTS 与本地 TTS 成本调研

日期：2026-09-13

目标：核对千问、腾讯 TokenHub、火山方舟三家 TTS 的真实价格和赠送额度，并与 github-podcast 当前本地 VoxCPM2 路线比较。

## 一句话结论

本地 VoxCPM2 的现金成本约为每期 1-2 分钱；云 TTS 在正常价下约为每期 1.36-4.25 元。两者不是同一个成本量级，但云 TTS 的绝对价格仍很低。是否换云，主要看音质、机器时间和稳定性，不是看电费。
