# 三家云 TTS 全景

## 先分清“平台”和“TTS 产品”

这三家都不能只看首页大字报价：

- 千问平台本身接 Qwen3-TTS、Qwen-Audio-TTS、CosyVoice、MiniMax，价格和免费额度按模型分别计算。
- 腾讯 TokenHub 里的 TTS 是 MiniMax Speech；TokenHub 的 100 万 tokens 新人免费包没有列 TTS。腾讯自己还有一套腾讯云语音合成，跟 TokenHub 不是同一个免费额度。
- 火山方舟里的 TTS 是 `doubao-seed-tts-2.0`；豆包语音又有一套独立购买入口和试用额度。方舟 Agent Plan 则用 AFP 抵扣。

## 结论

1. 论现金成本，本地碾压云 TTS，约差 50-200 倍。
2. 论绝对成本，云 TTS 并不贵。最便宜的千问约 1.36 元/期，一个月 30 期约 40 元。
3. 论免费额度，腾讯云自有 TTS 的 800 万基础/精品字符最夸张，但接口和音色限制最多，不能直接等同于高质量播客路线。
4. 论免迁移，继续用本地 VoxCPM2；论省时间和音质试错，千问最值得先拿免费额度试。
5. 当前账号的具体免费 TTS 总额度约 40K chars；保守折算约 2 万汉字，约 2.35 期。
