# samples/ —— 两期实物样例

这个目录不放源码，放**产出物**。流水线值不值得抄，看它真跑出来什么比看脚本直接。

| 样例 | 是什么 | 为什么挑它 |
|---|---|---|
| `ep16-real-world-benchmarks/` | 一期完整的现代周期：主稿 15,109 汉字 + 36 字段拆解笔记 + 期页 | 现在是这个口径：主稿 8500-10500 + 常驻「本周新闻」1500-1900，三个项目拼盘，逐文件读过源码 |
| `ep1-whisper-cpp/` | 第一期，1,653 汉字的口径样板 | 全项目文稿口径的源头（见根目录规则「文稿口径」）。**短是故意的**——它是风格样板不是时长样板 |

每期三件套：

- `script.md` —— 口播稿。中文口语、讲给「你」听、概念配生活类比、结尾给一条判断标准
- `breakdown.md` —— 拆解笔记。**这是验收闸真正验的东西**：字段标题数、字节数、含具体数字的行数。
  没有它，脚本无从判断 agent 有没有真去读源码
- `page.md` —— 期页。双链存档，用 `[[ep<N>-<slug>]]` 互指

注意样例里的双链（`[[ep15-assertions]]` 等）指向**没有随本仓发布**的期次——公开的是这两期，
不是全部 16 期。链接是纯文本，指不到也不影响任何脚本。
